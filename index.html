2. Элементы оформления

В HTML имеется масса стандартных тегов для разделения содержимого сайта в отдельные блоки <header>, <main>, <footer>, <article>, <nav> и т. д. Всё это есть в интернете в справочниках по HTML. Каждый блок можно офрмить по своему усмотрению, установить отступы, настроить цвета, сделать рамки и т.п..

Чтобы текст не выглядел как одна бесконечная строка его можно разбить на параграфы и озаглавить, его (текст) можно выделить подчеркнуть или зачеркнуть, сделать отступы между параграфами, вставить горизонтальную линию, создавать списки, вставлять таблицы и изображения. Короче - полный набор для творчества, главное не утонуть во всём этом.

Карточку можно выделить отдельно и задать для неё свой стиль. Стили можно задавть прямо в .html файле или в файле .css


3. Ссылки

Чтобы сделать ссылку на место внутри страницы, нужно действовать в два шага:
- сначала задать уникальный id элементу,
- затем создать ссылку, которая указывает на этот id через href с символом #.
Это удобный способ организовать навигацию по длинным документам.
Помимо ссылок внутри страницы можно делать ссылки на другие ресурсы. В этом случае в качестве значения атрибута href используется адрес документа (URL, Universal Resource Locator), на который нужно перейти. Это может быть ссылка на другую страницу, сайт, Email или телефон.

5. Боковая панель

Это боковая панель, а в левой стороне страницы - сайдбар

Боковая панель и сайдбар — это не одно и то же! Если <aside> используется внутри тегов <section> или <article>, контент должен быть «связан» с ним. Если <aside> используется вне тегов <section> или <article> — например, непосредственно внутри <body> — он содержит контент, связанный с сайтом, например: дополнительную навигацию, последние публикации в блоге, последние комментарии и т. д.
Ошибкой будет поместить основной элемент, который визуально оформлен в виде боковой панели (например, логотип или главную навигационную панель), в тег <aside>. <aside> лучше использовать в соответствии со смыслом контента, который он несет, а не с визуальным аспектом сайта — эту часть нужно оформлять только с помощью CSS.

6. Списки

Списки в HTML бывают обычно трех видов: маркированные, нумерованные и списки определений. Пример нумерованного и маркированного списков (кстати, списки могут быть вложенными) приведён в начале.

Отдельная категория - списки определений. Выглядит примерно так:

Переходные процессы
Процессы, которые возникают в электрических цепях после того, как один из параметров цепи испытал скачкообразное (очень быстрое) изменение. Например, подключенный к цепи источник ЭДС (генератор тока или напряжения) формирует прямоугольный импульс напряжения или тока, или в цепи c подключенным постоянным источником ЭДС происходит коммутация отдельных элементов цепи с помощью ключей.
Генератор напряжения
Устройство, напряжение на выходе которого не зависит от величины тока, протекающего через этот генератор. Внутреннее сопротивление такого генератора принимается равным нулю, а в реальности – это источник ЭДС с внутренним сопротивлением, много меньшим сопротивления внешней цепи.
